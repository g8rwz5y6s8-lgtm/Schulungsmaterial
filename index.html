Wichtige Regeln aus dem Rechtskataster

  • Abteilung (Dropdown) → Verantwortlichkeit wird automatisch gesetzt (nicht editierbar).
  • Status Quo (Dropdown) mit Ampellogik: Implementiert (grün), In Bearbeitung (gelb), Nicht vorhanden (rot).
  • Last Check: aktuelles Datum unter Windows per Strg + Punkt.
  • Zyklus (Dropdown): Jährlich/Halbjährlich neutral, Quartalsweise gelb, Monatlich rot.
  • ID ist fortlaufend für eindeutige Referenzen (z.B. E-Mail, Filter).

Challenge – Audit Ready

Ziel: In kurzer Zeit die kritischen Stellen identifizieren und Pflege-Standards anwenden.

Aufgaben

  1. Öffne das Übungs-Sheet.
  2. Setze in 2 Zeilen den Status Quo auf „Nicht vorhanden“ und prüfe, ob die Zellen rot werden.
  3. Wähle in einer Zeile „Product Management“ und prüfe, ob Thomas automatisch bei Verantwortlichkeit steht.
  4. Trage in 2 Zeilen ein Datum in Last Check ein (z.B. via Strg + Punkt).

Übungs-Sheet (Excel-Look)

Diese Tabelle simuliert den Aufbau des Rechtskatasters (Excel-Optik) inkl. Dropdowns, Ampelfarben und automatischer Verantwortlichkeit.

Übungsaufgaben (Auto-Prüfung)

Erledige die Aufgaben in der Tabelle und klicke dann auf „Aufgaben prüfen“. Jede Aufgabe gibt nur einmal Punkte.

  1. Zeile/ID 3: Setze Status Quo auf „Nicht vorhanden“ (Zelle muss rot werden).
  2. Zeile/ID 1: Wähle Abteilung „Product Management“ → Verantwortlichkeit muss automatisch Thomas sein.
  3. Last Check: Trage bei mindestens 2 Einträgen ein Datum ein (z.B. Windows: Strg + Punkt).
  4. Zeile/ID 6: Setze Zyklus auf „Quartalsweise“ (Zelle wird gelb).
